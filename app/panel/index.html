    How to connect Perplexity

    About two minutes, once. After that this panel is where you approve what Perplexity wants to change.

    1. Copy your connector URL

      This is the address Perplexity uses to reach this computer. It contains a secret key, so treat it like a password.

      The URL appears here after Cloudflare setup.

    2. Add it in Perplexity

      1. Open Perplexity, then Customize > Connectors (or the Plugins page).
      2. Press Add custom > Connector, then Add MCP connector.
      3. Name: Perplexity On Steroids. MCP Server URL: paste the address you copied.
      4. Open Advanced. Authentication: None (see the red note below). Transport: Streamable HTTP.
      5. Acknowledge the risk and press Add. Perplexity validates the connector by calling pos_ping.
      Important: open Advanced and set Authentication to None. Perplexity picks OAuth by default, and with OAuth the connector fails with [API_CLIENTS_ERROR] Server does not support automatic registration. Leave Client ID and Client Secret empty. (Pick API Key only when you started the server with POS_TOKEN.)

    3. Try it in a chat

      Start a chat and ask: What's in C:\Users\me\Desktop? or Run the pos_ping tool. The activity table fills as calls arrive, and the top of the panel turns to Perplexity connected.

    4. Day to day

      • Keep the server open. The Cloudflare relay reconnects on its own after a restart.
      • Access limits file tools and the initial working directory of commands. It does not sandbox shell commands. Keep roots to the project you are working on and disable commands when not needed.
      • Permissions chooses what waits for approval. Deletes and destructive commands always ask unless you pick "No restrictions".

    5. If something is off

      • "Server does not support automatic registration": Authentication is on OAuth. Open Advanced and set it to None.
      • Perplexity cannot validate the connector: the relay is offline. Press Restart tunnel and check the panel.
      • Connector offline in Perplexity: start this server, then try again. The URL stays the same.
      • 401: the server has POS_TOKEN set but the connector has no API key or the wrong one.
      • Unknown tool: remove and re-add the connector, Perplexity caches the tool list.
      • Read-only errors: choose a looser mode under Permissions.
